## THE FIX — buildIndex's byName map (public/family.js, block at ~lines 155-165)

Today:

    var byName = new Map();
    byId.forEach(function (p) {
      if (typeof p.name !== 'string' || !p.name) return; // synthetic fixtures
      var key = p.name.toLowerCase();
      if (!byName.has(key)) byName.set(key, p);   // FIRST ONE WINS — later
                                                  // same-named people vanish
    });

Change byName to a MULTI-MAP: Map<lowercasedName, Array<person>> containing
EVERY person with that name, in data file order. Keep skipping nameless
synthetic fixtures. Update the comment above it to say the map holds all
same-named people (first-to-last in data order) because same-named people are
distinct individuals. Nothing else in app.js or family.js reads byName today
(verified — zero consumers), so this is a self-contained change, but keep the
exported index shape otherwise identical ({ byId, byName, childrenOf,
siblingsOf, spousesOf, problems }).

Do NOT add any name-based disambiguation UI, name suffixes, or auto-renaming —
the owner did not ask for that. Distinctness is the requirement, not relabeling.
